How a Soroban thinks

A soroban is a calculator you can touch. Each rod is one digit. The beam in the middle is the counting line.

1 rod = 1 digit

Right rod = ones, next = tens, next = hundreds. Just like writing numbers!

Top bead = 5

Slide it down to the beam to add 5. Slide it up to take 5 away.

Bottom beads = 1 each

Slide them up to the beam. Four beads make 0–4, plus the 5-bead makes 0–9.

Try the secret codes

Friends of 5: 1+4, 2+3. Friends of 10: 1+9, 2+8, 3+7, 4+6, 5+5. These combos let you add even when a rod looks full!

How Abby works

Abby is a coach that speaks “abacus”. The site sends your recent answers to the server, which estimates your level (1–5) and asks Meta's Llama API for a short, fun hint — or uses a built-in coach if no API key is configured.

To enable Meta AI: get a key from llama.developer.meta.com, set META_API_KEY, restart with npm start.
